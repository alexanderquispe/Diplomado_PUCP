# Skills_Claude — Peru BCRP Macro Dashboard

A self-contained Claude Code project that connects a live **BCRP (Banco Central de Reserva del Perú)** data feed to a Streamlit dashboard through a local MCP server and a Claude Code skill (`/bcrp-dashboard`).

---

## Project structure

```
Skills_Claude/
├── .claude/
│   ├── settings.json               ← Project-level MCP server wiring (auto-loaded by Claude Code)
│   ├── commands/
│   │   └── bcrp-dashboard.md       ← Slash command (project scope)
│   └── skills/
│       └── bcrp-dashboard.md       ← Skill visible in /skills dialog (project scope)
├── .venv/                          ← Python virtual environment (not committed)
├── mcp_bcrp_server.py              ← FastMCP server — exposes BCRP tools to Claude
├── fetch_bcrp.py                   ← Standalone helper to fetch and save bcrp_data.json
├── dashboard.py                    ← Streamlit dashboard (written/updated by the skill)
├── start_mcp_bcrp.cmd              ← Windows wrapper for global MCP registration
├── requirements.txt                ← Python dependencies
├── setup.ps1                       ← One-time venv setup script
└── .gitignore                      ← Excludes .venv/, bcrp_data.json, __pycache__/
```

## Where everything lives

### MCP server

| Scope | Location |
|---|---|
| Server script | `Skills_Claude/mcp_bcrp_server.py` |
| Project config | `Skills_Claude/.claude/settings.json` |
| Global registration | `~/.claude.json` (written by `claude mcp add --scope user`) |
| Global wrapper script | `Skills_Claude/start_mcp_bcrp.cmd` |

The server is registered **globally** so it is available in every Claude Code session, not just when opened from this folder.

To verify: run `claude mcp list` in any terminal — you should see:
```
bcrp: C:\...\start_mcp_bcrp.cmd  - ✓ Connected
```

## How it works end-to-end

```
User types /bcrp-dashboard
        │
        ▼
Claude Code loads ~/.claude/skills/bcrp-dashboard.md
        │  (skill instructions become Claude's context)
        ▼
Claude calls get_macro_snapshot() or individual series tools
        │  (via MCP protocol over stdio)
        ▼
start_mcp_bcrp.cmd  →  mcp_bcrp_server.py  →  BCRP REST API
        │  https://estadisticas.bcrp.gob.pe/estadisticas/series/api/{code}/json/{start}/{end}
        ▼
Returns JSON with "periods" array: [{"name": "Ene.2024", "values": ["2.4"]}, ...]
        │
        ▼
Claude parses response, writes dashboard.py with embedded data
        │
        ▼
Claude launches: .venv\Scripts\streamlit run dashboard.py (background)
        │
        ▼
Dashboard live at http://localhost:8501
```

### MCP transport

Claude Code uses **stdio transport**: it spawns the MCP server as a child process, communicates over stdin/stdout, and kills it when the session ends. No manual `python mcp_bcrp_server.py` is needed — the server starts and stops automatically with each Claude Code session.

## MCP tools exposed

All tools are defined in `mcp_bcrp_server.py`:

| Tool | Parameters | Description |
|---|---|---|
| `get_inflation(start, end)` | `YYYY-MM` | Monthly CPI % variation |
| `get_exchange_rate(start, end)` | `YYYY-MM` | Average USD/PEN exchange rate |
| `get_gdp(start, end)` | `YYYY-MM` | Seasonally adjusted GDP index |
| `get_interest_rate(start, end)` | `YYYY-MM` | BCRP reference rate (% annual) |
| `get_trade_balance(start, end)` | `YYYY-MM` | Accumulated exports (millions USD) |
| `get_macro_snapshot(months)` | integer (default 12) | All indicators in one call |

### Verified BCRP series codes

| Indicator | Code | Notes |
|---|---|---|
| Inflation (IPC) | `PN01271PM` | Monthly % variation |
| Exchange rate | `PN01234PM` | Monthly average S/ per USD |
| GDP | `PN01773AM` | Seasonally adjusted index, base 2007 |
| Interest rate | `PN07819NM` | BCRP monetary policy rate |
| Trade balance | `PN01781AM` | Accumulated exports, millions USD |
| Reserves | `PN01265GM` | Net international reserves |

## Dashboard layout

The Streamlit app (`dashboard.py`) uses `layout="wide"` and Plotly charts:

- **Header** — title + last update timestamp
- **5 metric cards** — latest value and delta vs. prior period for each indicator
- **Row 1** — Inflation bar chart (BCRP band 1%–3% annotated) | Exchange rate line chart (max/min annotated)
- **Row 2** — GDP line + linear trend | Interest rate step chart (filled)
- **Row 3** — Trade balance full-width bar (red = deficit)
- **Footer** — BCRP series codes used

Colors: BCRP red `#C8102E` · BCRP navy `#003087`

## Daily usage

Open Claude Code from any folder and type:

```
/bcrp-dashboard
```

Claude will:
1. Call `get_macro_snapshot()` to fetch live BCRP data
2. Write/overwrite `dashboard.py` with the latest data
3. Launch Streamlit automatically in the background
4. Report: "Dashboard actualizado y lanzado en http://localhost:8501"

To check MCP server status:
- In terminal: `claude mcp list`
- In Claude Code chat: `/mcp`

To view available skills:
- In Claude Code chat: `/skills`

## Notes

- `bcrp_data.json` is excluded from git (`.gitignore`) — it is regenerated each time the skill runs.
- The `.venv/` folder is also excluded from git — run `setup.ps1` after cloning.
- The MCP server process lives only while Claude Code is open. It is not a Windows service.
- The BCRP API is public and requires no authentication.
